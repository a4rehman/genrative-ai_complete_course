# Exercises: Tool Using Agents

## Intuition
1. Explain Tool Using Agents in simple English.
2. Draw the AI workflow using boxes and arrows.
3. Identify the model input, context, tool calls, and output.

## Coding
1. Run practice.py.
2. Modify the prompt template for a business use case.
3. Add one validation rule for unsafe or low-quality output.
4. Replace the mock LLM with a real provider when your API key is configured.

## Evaluation
1. Write five test prompts for this topic.
2. Define what a good answer must include.
3. Track latency, cost, and correctness.

## Production Thinking
1. What can go wrong in a real enterprise system?
2. What data should be logged or redacted?
3. When should a human approve the output?
