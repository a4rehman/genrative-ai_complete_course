# Mini Project: OpenAI Function Calling

## Goal
Build a working GenAI demo that applies OpenAI Function Calling to a realistic user problem.

## Requirements
- Define the user persona and task.
- Create a prompt, chain, retriever, tool, agent, or workflow.
- Add a simple evaluation checklist.
- Include at least one safety or validation rule.
- Document latency, cost assumptions, and production risks.

## Suggested Deliverables
- solution.py or notebook experiment.
- Prompt templates or workflow diagram.
- Short README explaining setup and limitations.

## Stretch Goals
- Add document upload or vector search.
- Add conversation memory.
- Add a tool/function call.
- Add LangGraph state management.
