# Interview Questions: FastAPI

1. Explain FastAPI to a non-technical stakeholder.
2. What architecture would you use for a production implementation?
3. How would you evaluate quality, cost, latency, and safety?
4. What prompt injection or data privacy risks exist?
5. How would you connect this concept to LangChain or LangGraph?
6. When would you use retrieval, tools, memory, or fine-tuning?
7. What failure modes would you monitor after deployment?
8. How would you design this for enterprise scale?

## Strong Answer Framework
Use: problem -> architecture -> data flow -> code pattern -> evaluation -> security -> deployment trade-offs.
